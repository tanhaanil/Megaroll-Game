# Introduction

Dice Game is one of my initial projects developed using the Flutter framework. 

The main purpose of this project was to learn the fundamentals of Flutter application development, including UI design, state management, user interaction, and implementing game logic using Dart programming.
This project is a simple dice-based game where players roll dice and follow specific rules to either win or lose the game. Learning Resource: Lead Academy
